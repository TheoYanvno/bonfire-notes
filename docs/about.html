About

Hi, I'm Anthony: Navy veteran, medical assistant and lifelong gamer. Bonfire Notes is where I write beginner-friendly guides and plain-language lore for Dark Souls, the game that taught a generation of players that dying is part of learning.

The site itself is a small project: posts are written in Markdown and turned into this static site by a Python script with Jinja templates. The floating embers are drawn with the HTML canvas.

Praise the sun, and don't go hollow.

Bonfire Notes is an unofficial fan blog. Dark Souls is a trademark of its owners; this site is not affiliated with FromSoftware or Bandai Namco.
